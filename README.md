# 🐍 Python: De lo Básico a la Inteligencia Artificial 🚀

Bienvenido/a al repositorio **Python**, un espacio para aprender y practicar Python desde cero hasta aplicaciones avanzadas en **Backend**, **Ciencia de Datos** e **Inteligencia Artificial**.

---

## 📂 Contenido del repositorio

| Carpeta | Descripción |
|---------|-------------|
| **Basic** | Fundamentos de Python: variables, tipos de datos, condicionales, bucles, funciones. |
| **Intermediate** | Temas intermedios: POO, manejo de errores, módulos, librerías externas. |
| **Backend** | Ejemplos y proyectos para crear APIs y aplicaciones backend con Python. |
| **IntroduccionIAConPython** | Introducción a la Inteligencia Artificial con Python y librerías populares. |
| **Python for Data Science** | Ciencia de datos con Python: Numpy, Pandas, Matplotlib, análisis exploratorio. |
| **Retos** | Ejercicios y desafíos de programación para poner a prueba tus habilidades. |
| **Utils** | Scripts y utilidades para proyectos en Python. |
| **PY0101EN** | Curso de introducción a Python en inglés. |
| **mbot2** | Proyectos y scripts relacionados con robótica y mbot. |

---

## 🎯 Objetivo
Este repositorio busca:
- Enseñar Python de forma progresiva.
- Proporcionar ejemplos y ejercicios prácticos.
- Mostrar aplicaciones reales en **Backend**, **Data Science** e **IA**.

---

## 🛠 Requisitos
- [Python 3.10+](https://www.python.org/downloads/)
- [pip](https://pip.pypa.io/en/stable/installation/)
- (Opcional) [Jupyter Notebook](https://jupyter.org/install)

---

## 🚀 Cómo usar este repositorio
1. **Clona el repositorio**
   ```bash
   git clone https://github.com/amariscalc/Python.git
   cd Python

2. **Crea un entorno virtual**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows

3. **Instala dependencias**
   ```bash
   pip install -r requirements.txt
